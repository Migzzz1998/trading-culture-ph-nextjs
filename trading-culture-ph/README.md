# Trading Culture PH — Next.js site

## Setup
1. Install dependencies: `npm install`
2. Run the dev server: `npm run dev`
3. Open http://localhost:3000

## Edit content
All broker/community placeholders live in `lib/config.js`. Update values there —
every component reads from this file automatically.

## Deploy
Push to GitHub, then import the repo at vercel.com. No extra config needed.
